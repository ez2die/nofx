# Prompt中RSI权重强化问题分析

## 问题确认

✅ **确实存在强化RSI权重的引导**，导致AI过度依赖RSI而忽略趋势指标（EMA/MACD）

## 核心问题

当前prompt中存在**隐性的RSI优先引导**，主要体现在：
1. RSI超卖被单独强调，缺乏与趋势指标的综合判断
2. "反弹"思维被强化，忽略了趋势方向的重要性
3. 指标权重不明确，AI可能过度依赖单一指标

## 修改原则

**目标：** 弱化RSI优先的引导，但不显性弱化RSI本身
- ✅ 强调趋势优先、多指标综合使用
- ✅ 通过调整表述顺序和强调其他指标来自然平衡权重
- ✅ **重要：所有偏向于强规则的prompt和案例表述都要明确标注为"参考案例"或"示例"，不作为强执行规则，将综合考量的权限还给AI**
- ❌ 避免直接说"RSI不重要"或"弱化RSI"
- ❌ 避免过度强调"不要用RSI"
- ❌ 避免将示例表述为强制规则

## 具体问题点与修改建议

### 1. 关注重点未明确指标优先级（第190行）

**当前内容：**
```
## 关注重点
趋势 + 动量 + 成交量 + 资金费率
```

**问题：**
- 没有明确指标的使用顺序和权重关系
- RSI未出现在关注重点中，但在实际决策中被过度使用

**建议修改（强调综合使用，明确为参考原则）：**
```
## 关注重点
**多指标综合判断，趋势优先（参考原则，非强制规则）**
- 趋势(EMA方向) + 动量(MACD) + 成交量 + 资金费率
- **参考原则**：超买超卖指标(RSI)通常作为辅助确认，需结合趋势方向解读
- **参考原则**：单一指标通常不足以做出决策，通常需要多个指标相互确认
- **注意**：以上为参考原则，你应根据实际市场情况综合判断，而非机械执行
```

### 2. 技术指标解读缺乏权重指导（第173行）

**当前内容：**
```
- **你的判断**：你决定如何根据当前市场条件加权和组合指标
```

**问题：**
- 给了AI完全自主权，可能导致过度依赖RSI
- 缺乏"多指标确认"的强调

**建议修改（强调综合判断，明确为参考原则）：**
```
- **你的判断**：你决定如何根据当前市场条件加权和组合指标
- **参考原则（非强制规则）**：通常需要综合多个指标，单一指标（包括RSI）通常不足以做出决策
  - **参考**：趋势指标(EMA)和动量指标(MACD)通常提供方向性信号
  - **参考**：超买超卖指标(RSI)通常需结合趋势方向解读：在明确趋势中，RSI的极端读数可能持续
  - **参考**：成交量通常验证所有信号的有效性
- **注意**：以上为参考原则，你应根据实际市场情况综合判断，而非机械执行
```

### 3. 趋势对齐检查位置和表述（第404行）

**当前内容：**
```
- [ ] **趋势对齐**：不逆明确趋势交易？（如果4小时趋势向下，不要仅因为RSI超卖就做多）
```

**问题：**
- 在Tier 3（质量过滤器），不是硬约束
- 表述"不要仅因为"暗示RSI仍可作为理由之一

**建议修改（提升重要性，强调综合判断，明确为参考案例）：**
```
- [ ] **趋势对齐（重要检查）**：结合趋势方向进行综合判断
  - 首先确认趋势方向（EMA与价格关系、MACD方向）
  - 然后结合RSI等指标进行综合判断
  - **参考案例（非强制规则）**：
    - 如果趋势向下（EMA > 价格，MACD < 0），即使RSI超卖，通常优先考虑趋势方向
    - 如果趋势向上（EMA < 价格，MACD > 0），即使RSI超买，通常优先考虑趋势方向
  - **注意**：以上仅为参考案例，你应根据实际市场情况综合判断，而非机械执行
```

### 4. "超卖反弹"表述需要平衡（第405行）

**当前内容：**
```
- [ ] **成交量确认**：成交量是否支持信号？（超卖反弹需要成交量确认）
```

**问题：**
- "超卖反弹"单独出现，暗示RSI超卖=开多信号
- 没有强调需要结合趋势方向

**建议修改（强调综合判断，明确为参考案例）：**
```
- [ ] **成交量确认**：成交量是否支持信号？
  - 所有信号都需要成交量确认，包括趋势确认和超买超卖确认
  - **参考案例（非强制规则）**：
    - 在上涨趋势中，RSI超卖+成交量放大可能确认反弹
    - 在下跌趋势中，RSI超卖+成交量放大可能确认继续下跌
  - **注意**：以上仅为参考案例，你应根据实际市场情况综合判断，而非机械执行
  - 必须结合趋势方向和其他指标综合判断
```

### 5. 弱势市场部分需要平衡"反弹"思维（第336-337行）

**当前内容：**
```
- **耐心等待信号稳定**：不要因为看到短期反弹信号就急于开仓，等待信号稳定后再行动
- **给反弹信号足够时间**：在弱势市场中，反弹信号可能需要更长时间来发展，过早开仓可能导致在信号尚未稳定时就被止损
```

**问题：**
- 多次提到"反弹信号"，暗示等待反弹（开多）
- 没有强调趋势方向的重要性

**建议修改（强调趋势优先，但不贬低反弹，明确为参考案例）：**
```
- **多指标综合判断**：在弱势市场中，综合多个指标判断
  - 首先确认趋势方向（EMA、MACD）
  - **参考案例（非强制规则）**：
    - 如果趋势明确向下，通常优先考虑趋势方向，而非单一指标的反弹信号
    - 只有在多个指标（趋势、动量、成交量）同时确认反转时，才考虑逆势操作
  - **注意**：以上仅为参考案例，你应根据实际市场情况综合判断，而非机械执行
- **耐心等待信号稳定**：不要因为看到单一指标信号就急于开仓，等待多个指标确认后再行动
  - **参考案例**：反弹信号通常需要趋势、动量、成交量的综合确认
  - **参考案例**：单一RSI超卖通常不足以作为开多理由
  - **注意**：以上仅为参考案例，你应根据实际市场情况综合判断
```

### 6. 入场假设示例需要平衡（第476行）

**当前内容：**
```
1. **引用入场快照**：识别入场假设的核心逻辑（RSI超卖反弹 / MACD金叉趋势 / 突破关键位等）。
```

**问题：**
- "RSI超卖反弹"作为第一个例子，强化了RSI优先
- 没有体现多指标综合判断

**建议修改（调整顺序，强调综合，明确为参考案例）：**
```
1. **引用入场假设**：识别入场假设的核心逻辑
   - **参考案例**：趋势类假设可能包括EMA方向变化 / MACD金叉或死叉 / 突破关键位
   - **参考案例**：综合类假设可能包括趋势确认 + 动量确认 + 成交量确认 + RSI等辅助指标
   - **参考案例**：单一指标（包括RSI）通常不足以作为入场假设，通常需要多个指标相互确认
   - **示例（仅供参考，非强制规则）**：
     - 示例1：EMA下跌趋势 + MACD负值 + 成交量放大 + RSI超卖 = 可能的做空信号
     - 示例2：EMA反转向上 + MACD转正 + 成交量放大 + RSI超卖 = 可能的做多信号
   - **注意**：以上仅为参考案例和示例，你应根据实际市场情况综合判断，而非机械执行
```

## 总结

### 修改策略

**核心思路：** 通过强调"多指标综合判断"和"趋势优先"来自然平衡RSI权重，而非显性弱化RSI

**关键修改点：**
1. ✅ 在"关注重点"中明确"趋势优先，多指标综合"（作为参考原则）
2. ✅ 在技术指标解读中强调"单一指标通常不足以决策"（作为参考原则）
3. ✅ 提升"趋势对齐"检查的重要性，但明确为参考案例
4. ✅ 调整表述顺序，将趋势指标放在RSI之前
5. ✅ 强调"综合判断"而非单一指标依赖
6. ✅ **重要：所有看似强规则的表述都要明确标注为"参考案例"、"参考原则"或"示例"，并说明"非强制规则"，将综合考量的权限还给AI**

**避免的做法：**
- ❌ 直接说"RSI不重要"
- ❌ 过度强调"不要用RSI"
- ❌ 完全移除RSI相关内容
- ❌ 将示例或参考案例表述为强制规则
- ❌ 使用"必须"、"应该"等强规则词汇，而不明确标注为参考案例

**重要原则补充：**
- ✅ 所有看似强规则的表述都要明确标注为"参考案例"、"参考原则"或"示例"
- ✅ 明确说明"非强制规则"、"仅供参考"
- ✅ 强调"你应根据实际市场情况综合判断，而非机械执行"
- ✅ 将综合考量的权限还给AI，避免过度约束

### 预期效果

通过这些修改，AI将：
- 优先考虑趋势方向（EMA/MACD）
- 将RSI作为辅助确认工具，而非主导决策
- 在下跌趋势中，看到RSI超卖时考虑做空而非等待反弹
- 综合多个指标做出决策，而非依赖单一指标
