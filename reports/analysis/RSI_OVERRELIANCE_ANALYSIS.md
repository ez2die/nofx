## 问题根源分析

### 1. RSI权重过高

AI在决策时过度看重RSI指标：
- 看到RSI < 30 (超卖) → 认为应该开多或等待反弹
- 忽略了RSI在强势下跌趋势中会持续超卖的事实

### 2. EMA趋势被忽略

EMA明确显示下跌趋势，但AI没有充分利用：
- EMA > 价格 → 应该做空或至少不做多
- 但AI在看到RSI超卖时，倾向于忽略EMA信号

### 3. MACD动量被低估

MACD持续负值且恶化，表明下跌动量加强：
- 但AI在看到RSI超卖时，认为"超卖反弹"即将到来
- 忽略了MACD显示的持续下跌动量

### 4. 趋势vs超卖的冲突处理不当

当RSI超卖但EMA显示下跌趋势时：
- **正确做法：** 优先考虑趋势(EMA)，RSI超卖在下跌趋势中可能持续
- **AI做法：** 优先考虑RSI超卖，认为应该等待反弹或开多

## 建议改进方案

### 1. 调整指标权重

**当前问题：** RSI权重过高

**建议：**
- **趋势指标(EMA)权重 > 超买超卖指标(RSI)权重**
- 当EMA显示明确趋势时，RSI应该作为辅助确认，而不是主导决策

### 2. 改进决策逻辑

**当前逻辑：**
```
RSI超卖 → 考虑开多或等待反弹
```

**建议逻辑：**
```
1. 首先判断趋势（EMA方向）
   - 如果EMA显示下跌趋势 → 优先考虑做空
   - 如果EMA显示上涨趋势 → 优先考虑做多
   
2. 然后看RSI
   - 如果趋势下跌 + RSI超卖 → 可以做空（超卖可能持续）
   - 如果趋势上涨 + RSI超买 → 可以做多（超买可能持续）
   - 如果趋势下跌 + RSI超买 → 等待或做空
   - 如果趋势上涨 + RSI超卖 → 等待或做多
```

### 3. 增加趋势确认机制

**建议：**
- 当EMA > 价格且MACD < 0时 → **强烈做空信号**
- 当EMA < 价格且MACD > 0时 → **强烈做多信号**
- RSI超卖/超买应该作为**入场时机优化**，而不是**方向判断**

### 4. 修改Prompt提示

在prompt中明确：
- **趋势优先原则：** EMA趋势 > RSI超买超卖
- **在下跌趋势中，RSI超卖不是开多的理由，而是做空的信号**
- **在上涨趋势中，RSI超买不是做空的理由，而是做多的信号**
