## 3. Prompt模糊性分析

### 3.1 模糊规则

#### 模糊规则 1: 建议 vs 要求

- **模糊类型**: vague
- **出现频率**: 16次
- **影响**: AI可能将建议误认为是要求，或忽略必须遵守的规则
- **示例**:
  - Prompt中同时包含'建议'和'必须'的表述，可能导致AI混淆

#### 模糊规则 2: 数值范围模糊

- **模糊类型**: vague
- **出现频率**: 55次
- **影响**: AI可能选择范围边界值，导致不符合预期
- **示例**:
  - 15-25
  - 12-22
  - 8-15
  - 5-8
  - 0.5-0.8

### 3.3 缺少清晰度的主题

#### 主题 1: 入场时机判断

- **问题**: Prompt中缺少明确的入场时机判断标准

## 5. Prompt修正建议

### 建议 1: 市场噪音在CoTTrace中提及率低 [high优先级]

**类别**: guidance

**当前Prompt**:
```
市场噪音考虑：止损应≥2-3×典型K线内波动性
```

**建议修改**:
```
在止损设置部分添加强制检查清单，要求AI在设置止损时明确说明是否考虑了市场噪音
```

**理由**: 只有12.5%的决策提到了市场噪音，导致止损设置过窄

**预期影响**: 减少因市场噪音导致的虚假止损触发

**证据**:
- 止损遵循率: 91.7%

### 建议 2: 风险回报比违反率高 [high优先级]

**类别**: constraint

**当前Prompt**:
```
风险回报比要求：绝对最小值3.0:1
```

**建议修改**:
```
在预执行检查清单中将风险回报比检查放在第一位，并添加'如果风险回报比<3.0:1，立即拒绝，不要寻找例外'的明确说明
```

**理由**: 风险回报比遵循率只有61.4%，存在32次违反

**预期影响**: 减少风险回报比违反次数

**证据**:
- 违反次数: 32
