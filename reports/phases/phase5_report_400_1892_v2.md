## 3. Prompt修正方案

### 3.1 修正方案摘要


共生成 6 个Prompt修正方案：

**高优先级修正**（5个）：
- 市场噪音在CoTTrace中提及率低
- 规则矛盾：耐心等待 vs 快速响应
- 规则矛盾：趋势优先 vs 多指标综合判断
- 风险回报比违反率高

**中优先级修正**（1个）：
- 参考原则与硬约束混淆

**预期效果**：
- 提高风险回报比遵循率
- 减少止损触发率
- 减少逆势交易
- 提高决策逻辑质量


### 3.2 高优先级修正

#### 修正 1: 市场噪音在CoTTrace中提及率低

**位置**: 止损设置部分（RISK MANAGEMENT > 止损设置 > 市场噪音考虑）

**当前文本**:
```
市场噪音考虑：止损应≥2-3×典型K线内波动性
```

**修正后**:
```
在止损设置部分添加强制检查清单，要求AI在设置止损时明确说明是否考虑了市场噪音
```

**理由**: 只有0.9%的决策提到了市场噪音，导致止损设置过窄

**预期影响**: 减少因市场噪音导致的虚假止损触发

**修正步骤**：

1. 在止损设置部分添加强制检查清单
2. 要求AI在设置止损时明确说明是否考虑了市场噪音
3. 在预执行检查清单中添加市场噪音检查项


#### 修正 2: 入场时机检查不足

**位置**: Prompt全文

**当前文本**:
```
信号持续时间验证：偏好信号已经持续了至少5-10分钟
```

**修正后**:
```
将入场时机检查提升为硬约束，要求AI在CoTTrace中明确说明信号持续时间，否则不允许开仓
```

**理由**: 只有0.0%的开仓决策检查了信号持续时间

**预期影响**: 减少在横盘/下跌趋势中做多的问题

**修正步骤**：



#### 修正 3: 规则矛盾: 耐心等待信号稳定 vs 快速响应入场假设失效

**位置**: MARKET ADAPTATION > 弱势市场 和 持仓熔断复核

**当前文本**:
```
两个规则同时存在但可能冲突
```

**修正后**:
```
明确说明何时应用哪个规则，添加决策树或优先级说明
```

**理由**: 两个规则可能在不同情况下同时适用，但AI可能混淆何时应用哪个规则

**预期影响**: 减少AI决策的不一致性

**修正步骤**：

1. 在决策流程中明确说明何时耐心等待，何时快速响应
2. 添加决策树：入场假设失效 → 快速响应；信号不稳定 → 耐心等待
3. 在持仓熔断复核中明确优先级


#### 修正 4: 规则矛盾: 趋势优先 vs 多指标综合判断

**位置**: DATA INTERPRETATION > 关注重点 和 DECISION PROCESS

**当前文本**:
```
两个规则同时存在但可能冲突
```

**修正后**:
```
明确说明何时应用哪个规则，添加决策树或优先级说明
```

**理由**: 当趋势与其他指标冲突时，AI可能不确定应该优先哪个

**预期影响**: 减少AI决策的不一致性

**修正步骤**：

1. 将趋势分析提升为决策流程的第一步
2. 明确说明：先判断趋势方向，再结合其他指标
3. 当趋势与其他指标冲突时，优先考虑趋势方向


#### 修正 5: 风险回报比违反率高

**位置**: CORE CONSTRAINTS > 风险回报比 和 PRE-EXECUTION CHECKLIST

**当前文本**:
```
风险回报比要求：绝对最小值3.0:1
```

**修正后**:
```
在预执行检查清单中将风险回报比检查放在第一位，并添加'如果风险回报比<3.0:1，立即拒绝，不要寻找例外'的明确说明
```

**理由**: 风险回报比遵循率只有0.0%，存在0次违反

**预期影响**: 减少风险回报比违反次数

**修正步骤**：

1. 在Prompt开头强调风险回报比要求
2. 在预执行检查清单中将风险回报比检查放在第一位
3. 添加'如果风险回报比<3.0:1，立即拒绝，不要寻找例外'的明确说明
4. 要求AI在CoTTrace中明确计算并说明风险回报比


### 3.3 中优先级修正

#### 修正 1: 参考原则与硬约束混淆

**位置**: DATA INTERPRETATION 和 MARKET ADAPTATION 部分

**当前文本**:
```
参考原则（非强制规则）
```

**修正后**:
```
明确区分硬约束和参考原则，使用不同的格式（如硬约束用【】标记，参考原则用（）标记）
```

**理由**: AI可能将参考原则误认为是硬约束，导致过度遵守或忽略

**预期影响**: 提高AI对规则层级的理解

**修正步骤**：

1. 使用【】标记硬约束
2. 使用（）标记参考原则
3. 在Prompt开头说明标记规则
