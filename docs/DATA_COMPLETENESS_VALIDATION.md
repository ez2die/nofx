## 改进建议

### 方案1：增加3分钟成交量序列（推荐）

**修改位置**：`market/data.go` 的 `calculateIntradaySeries` 函数

**修改内容**：
```go
// 在 IntradayData 结构体中增加
type IntradayData struct {
    MidPrices   []float64
    EMA20Values []float64
    MACDValues  []float64
    RSI7Values  []float64
    RSI14Values []float64
    ATR14Values []float64
    VolumeValues []float64  // 新增：3分钟成交量序列
    AverageVolume float64    // 新增：3分钟平均成交量
}
```

**在 `Format` 函数中输出**：
```go
if len(data.IntradaySeries.VolumeValues) > 0 {
    sb.WriteString(fmt.Sprintf("Volume indicators (3‑minute): %s\n\n", formatFloatSlice(data.IntradaySeries.VolumeValues)))
    sb.WriteString(fmt.Sprintf("Average Volume (3‑minute): %.3f\n\n", data.IntradaySeries.AverageVolume))
}
```

**优点**：
- 最小化修改，只增加成交量序列
- 可以准确判断短期成交量激增
- 支持快速变化市场识别

**缺点**：
- 需要修改数据结构
- 增加数据量（但影响很小）

### 方案2：使用4小时成交量作为替代（不推荐）

**问题**：
- 4小时成交量无法准确反映短期（<10分钟）的成交量变化
- 可能误判或漏判快速变化市场
