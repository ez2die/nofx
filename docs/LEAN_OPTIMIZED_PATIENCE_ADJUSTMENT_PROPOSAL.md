# lean_optimized.txt 调整建议：应对缺乏耐心和过于敏感问题

**问题来源**：Cycle 73-74 回测分析  
**核心问题**：过度反应短期波动，缺乏耐心，时间稳定性验证不足

---

## 问题分析

### 当前问题表现

1. **过度反应短期波动**：
   - Cycle 73：价格仅短暂跌破EMA20（2983.30 vs 2995.262），但6分钟内就修复
   - 立即平仓导致错失反弹机会

2. **缺乏耐心**：
   - 没有给反弹信号足够的时间发展
   - 基于超短期信号（<6分钟）做出平仓决策

3. **时间稳定性验证不足**：
   - 判断"关键技术位被破坏"，但市场在6分钟内就修复
   - 说明这个"破坏"信号是超短期的，不符合"10+分钟有效"的要求

**建议调整为**：
```
## 持仓熔断复核（Sharpe < 0 或持仓超过3个周期时必须执行）

### 时间窗口要求（关键）
**重要**：在判断"原始假设失效"之前，必须等待足够的时间窗口来确认趋势变化：
- **最小确认时间**：至少等待**10-15分钟**（3-5个决策周期）来确认趋势变化
- **避免过度反应**：不要因为价格短暂跌破/突破关键技术位就立即平仓
- **趋势变化确认**：只有当技术位被破坏**且持续10+分钟**时，才考虑平仓

**常见错误**：
- ❌ 价格短暂跌破EMA20（<6分钟）→ 立即平仓 → 错失反弹
- ✅ 价格跌破EMA20且持续10+分钟 → 确认趋势变化 → 平仓

### 原始假设检验流程

1. **引用入场快照**：确认核心驱动（趋势、动量、资金、结构）是否仍成立
2. **时间窗口验证**：
   - 如果技术位被破坏，等待至少10-15分钟来确认
   - 检查是否在多个K线上持续（3+根K线显示相同模式）
   - 避免基于单根K线或分钟级变动做出决策
3. **趋势变化确认**：
   - 价格跌破/突破关键技术位**且持续10+分钟**
   - 多个指标（RSI、MACD、EMA）同时恶化/改善
   - 成交量确认趋势变化（如反弹需要成交量支撑）

### 决策响应原则

- **若假设失效且持续10+分钟**：提出明确的 close_* / 调整止损方案
- **若假设暂时失效但<10分钟**：继续持有，等待确认
- **若假设仍成立**：保持 hold，并在 reasoning 中说明证据

**关键原则**：
- **耐心等待**：给市场足够的时间来验证信号的有效性
- **避免过度反应**：不要因为短期波动就放弃持仓
- **时间稳定性**：持仓管理决策也需要满足"10+分钟有效"的要求
```
