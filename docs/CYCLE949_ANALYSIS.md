## 根本原因

### 问题1: AI决策逻辑不一致

AI在思维链中明确说"必须执行止损上移至入场价"，但选择了 `hold` action，而 `hold` action 在系统中不会执行止损更新操作。

### 问题2: 系统不支持在hold时更新止损

当前系统设计：
- `open_long/open_short`: 可以设置止损
- `close_long/close_short`: 平仓
- `hold`: 仅记录，不执行任何操作
- **缺少**: 在持仓时更新止损的机制

### 问题3: Prompt指导与系统能力不匹配

Prompt中要求：
```
**入场假设失效** → 立即平仓或把止损上移至入场价（保本退出），不要等待时间窗口确认。
```

但系统实际能力：
- ✅ 支持 `close_long` 平仓
- ❌ **不支持** 在 `hold` 时更新止损

## 解决方案建议

### 方案1: 修改AI决策逻辑（推荐）

当入场假设失效时，AI应该：
- **使用 `close_long` 平仓**，而不是 `hold`
- 在 `reasoning` 中说明："入场假设失效，执行保本退出"

### 方案2: 增强系统能力

在 `hold` action 时支持止损更新：
- 如果 JSON 中包含 `stop_loss` 字段，执行止损更新
- 修改 `executeDecisionWithRecord` 函数，在 `hold` case 中检查并更新止损

### 方案3: 明确Prompt指导

在Prompt中明确说明：
- 当需要止损上移时，**必须使用 `close_long` 平仓**，而不是 `hold`
- `hold` 仅用于"继续持有，无需调整止损"的情况
